# Dossier du portfolio

Le dossier contient les documents de présentation, le rapport Power BI original dans rapport/, le classeur fourni et deux CSV dans donnees/.

Commencer par README.md. VERIFICATION.md décrit les contrôles réussis et les limites de l’inspection du rapport. METHODE.md explique les calculs ; DICTIONNAIRE.md décrit les variables. PUBLICATION-LINKEDIN.md propose un texte prêt à relire.

Les 150 observations préparées concordent avec la feuille Data du classeur. Le PBIX est conservé sans modification. Son actualisation sur un autre ordinateur peut nécessiter de repointer la source vers le classeur inclus. Aucun dépôt GitHub ni publication LinkedIn n’a été créé.
